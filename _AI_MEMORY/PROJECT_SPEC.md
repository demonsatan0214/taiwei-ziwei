# 專案規格書（PROJECT_SPEC）— 太微命判・黃進長紫微斗數

## 1. 核心人物與品牌背景
- **主理老師**：**黃進長** 老師（業主之父親）
- **品牌名稱**：**太微命判**（取自老師於武陵出版社發行之代表作名稱）
- **代表著作（武陵出版社・紫微系列）**：
  1. **《紫微斗數太微命判：論個性不必看命宮，論流年以生日為準》**
     - 出版日期：2008 年 8 月｜ISBN：`9789573513575`
     - 商品頁：`http://www.woolin.com.tw/?action=productDetails&id=55`
     - 核心創見：提出極具邏輯架構的推命論述，主張「論個性不必看命宮」、「論流年以生日為準」，並強調以**星曜得位、失位**與**體盤／用盤**概念推論吉凶。
  2. **《太微命判談星性：以星曜組合推論吉凶》**
     - 出版日期：2009 年 8 月｜ISBN：`9789573513773`
     - 核心創見：深入拆解紫微斗數三十二顆常用甲級星的星曜特性與組合吉凶。

## 3. 視覺與 UI/UX 設計規範
- **色彩系統（深邃星空 × 帝王金 × 朱砂印章）**：
  - 背景主色：`#0b0f22`（深夜空藍）、`#131936`（卡片次深藍）、`#1b2347`（高光深藍）
  - 金色主調：`#d6b46a`（古銅金）、`#f4dfa6`（亮香檳金）
  - 點綴朱紅：`#b8322a` / `#d6453d`（傳統印章朱砂紅）
  - 命盤宣紙：`#f7f0e2`（溫潤宣紙底色，讓傳統十二宮方盤清晰易讀）
- **字體規範**：
  - 標題與命盤星曜：`Noto Serif TC`（思源宋體，展現命理名家沉穩權威感）
  - 內文與操作介面：`Noto Sans TC`（思源黑體，確保手機與電腦清晰易讀）
- **雙端響應式（RWD）鐵則**：
  - 必須同時完美支援 **電腦寬螢幕（1180px 容器）**、**平板（960px 斷點）** 與 **手機直向螢幕（560px / 480px 斷點）**。
  - 注意 CSS 容器污染問題：例如 `#master` 內部的雙欄 Grid 必須使用獨立 class（如 `.master-grid`），不可直接寫在 `.master .wrap` 上，以免同區塊下方的全寬度元件（如 01–04 步驟卡）被擠入窄欄。
