# 未來開發路線圖（Technical Roadmap）

本文件供後續接手之施工 AI 規劃從「展示原型（Phase 1）」升級至「正式商用系統（Phase 2 & 3）」之技術路徑。

---

## Phase 1：品牌視覺與互動展示版（✅ 已完成）
- 單頁式高質感響應式網頁（[`index.html`](../index.html)），支援電腦、平板、手機瀏覽。
- 內建動態天干地支星盤、十二生肖流日運勢、十二宮命盤點擊切換、預約日曆互動、結帳與 LINE 諮詢彈窗。
- 託管於 GitHub Pages：`https://demonsatan0214.github.io/taiwei-ziwei/`。

---

## Phase 2：真實排盤引擎＋老師規則庫＋金流與預約後台（下一步規劃）
1. **真實紫微斗數排盤引擎整合**：
   - 前端或後端整合開源紫微排盤核心（如 `iztro`），支援國曆／農曆轉換、真太陽時校正、閏月處理，即時算出真實十二宮主星、輔星、四化、大限、流年、流月。
2. **「太微命判」專屬斷語知識庫（結合 AI 生成）**：
   - 將黃進長老師《紫微斗數太微命判》與《太微命判談星性》中之核心規則（星曜得位／失位判定表、生日為準之流年算法、32 顆甲級星組合吉凶）結構化為 JSON 規則庫與 Prompt。
   - 當客人購買 $150 / $300 / $500 方案時，系統先以精確演算法取得命盤宮位結構，再依據黃老師的規則庫自動生成符合「太微命判」風格的個人化報告與 PDF 命書。
3. **線上金流與 LINE 自動預約通知**：
   - 金流串接：藍新金流（NewebPay）或綠界（ECPay）＋ LINE Pay。
   - 預約通知：串接 LINE Official Account Messaging API，當客人完成 $1,000 親算預約與付款後，自動發送 LINE 通知給黃老師與客人，並在論命前 1 小時自動推播視訊連結。
